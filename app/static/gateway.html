规则差分台 TCP 访问网关

TCP 访问网关管理

按有序 IPv4/TCP 规则放行，首条命中、默认拒绝；启用规则后，失去权限的已建立长连接会立即被断开，仍获准的连接不中断。

编辑并启用规则（最多 20 条）

规则切换是原子操作：校验失败时不会影响当前活动规则与连接。
规则格式（沿用差分台格式）：id（同一组内唯一）、 source/destination（严格 IPv4 CIDR）、 portRange（目的端口闭区间）、action（allow/deny）。 判定使用真实对端源 IP 与启动配置固定的上游 IPv4 地址、端口；客户端自报地址不参与判定。 
[
  {"id": 1, "source": "0.0.0.0/0", "destination": "0.0.0.0/0",
   "portRange": [9000, 9000], "action": "allow"}
]

活动规则

暂无活动规则（默认拒绝所有连接）。

当前连接（每 2 秒自动刷新）

当前没有连接。
长连接撤权演示：先启用一条允许规则（本地直连可用 127.0.0.1/32， Docker 环境通常用 0.0.0.0/0），然后用 nc 127.0.0.1 9001 建立会话并收发数据；把规则改成拒绝后再发送数据，可看到连接立即被关闭。 也可运行 python scripts/demo_revoke.py 自动完成整个流程。
